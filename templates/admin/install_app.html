{{ app_name }} Price Checker

Puts the counter screen on this device as an app: its own icon, its own window, no browser bars. Sign in once inside the app and it stays signed in. Prices always come live from the server.
  Open the counter screen

Android phone or tablet (Chrome)

  1. Open this page on the device and sign in to the admin.
  2. Tap Install app above — or the browser's ⋮ menu, then Install app / Add to Home screen.

iPhone or iPad (Safari)

  1. Open this page in Safari and sign in to the admin.
  2. Tap Share (the square with the arrow), then Add to Home Screen, then Add.
  3. Open it from the new icon. Apple offers no install button to web pages, so this is the only way on iPhone and iPad.

Windows or Mac computer (Chrome or Edge)

  1. Click Install app above, or the install icon at the right-hand end of the address bar.
  2. The app gets a Start menu / Dock icon and opens in its own window.
